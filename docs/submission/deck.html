The problem

Risk paralysis.

Give a language model a brokerage API and it finds a reason to trade. Put a filter in front of it and it finds a reason to never trade.

Both failures look identical from the outside — a flat equity curve and a confident explanation. Nobody can tell an agent with discipline from an agent that is simply broken, because nobody measures the trades that were not taken.

The core innovation

Every refusal becomes a testable claim.

01

Refuse

The gate vetoes a spread and logs its legs, credit and reason to an append-only ledger.

02

Re-price

Those exact legs are re-priced later at live marks — what the refused trade would have earned.

03

Grade

Scored symmetrically. A refusal that avoided a loss counts; so does one that missed a profit.

04

Recalibrate

The threshold moves on the evidence, and the scorer keeps grading the new one.

Before execution, a 20,000-path Monte Carlo prices the distribution — probability of profit, 95% VaR, expected shortfall. A trade with negative expected value is refused however much premium it appears to pay.

Ecosystem value

Alpaca options production hardening.

Three undocumented behaviours, each found by running against the live API, each carrying a workaround any team building options on Alpaca will need.

  • Multi-leg limit sign is inverted. A positive net limit is read as a maximum debit — it silently authorises paying to enter a credit spread.
  • Greeks require --feed indicative. The default feed 403s without an OPRA agreement; snapshots return nulls and delta targeting dies quietly.
  • Intraday portfolio history is wrong in paper. Reports exactly $100,000 too high.

MIT licensed. The workaround layer is the contribution: it turns Alpaca's options API from something you discover by trial into something you build on.
